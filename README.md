# 🏋️ Telegram-бот для учёта тренировок по армрестлингу

Асинхронный Telegram-бот на Python (aiogram 3) для автоматизации учёта тренировок, постановки целей и коммуникации между тренером и учениками.

## 🚀 Возможности
- **Быстрый ввод тренировок**: парсинг естественного языка (например, `Жим 20 3 10, Пронация 15 4 12`).
- **Двусторонний чат**: защищённый канал связи тренера и ученика с историей переписки.
- **Система приглашений**: генерация уникальных ссылок и QR-кодов для регистрации новых учеников.
- **Аналитика**: графики прогресса (Matplotlib), статистика, рейтинг, серии тренировок.
- **Админ-панель**: управление учениками (блокировка/разблокировка), экспорт данных в CSV, массовые напоминания.
- **Фоновые задачи**: автоматические уведомления о неактивных пользователях (14+ дней без тренировок).

## 🛠 Стек технологий
- **Язык**: Python 3.10+
- **Фреймворк**: aiogram 3.x (асинхронный)
- **База данных**: SQLite + aiosqlite
- **Дополнительно**: matplotlib (графики), qrcode (генерация QR), python-dotenv
